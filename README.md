CLI Task Manager

A simple command-line task management application built using Node.js. This project allows users to add, view, update, and delete tasks directly from the terminal.

Features

Add new tasks

View all tasks

Update existing tasks

Delete tasks

Automatically generate unique task IDs

Validate user input

Handle invalid commands

Handle tasks that do not exist

Tech Stack

Node.js

JavaScript

File System (fs module)

JSON

Project Structure

CLI-Task-Manager/
├── index.js
├── tasks.json
├── package.json
└── README.md

Concepts Learned

Command-line arguments using process.argv

File handling using Node.js fs module

JSON parsing and stringification

Array methods: push(), forEach(), filter(), and map()

Unique ID generation using Math.max()

Input validation and error handling

Git and GitHub basics

Learning Outcome

Built a functional CLI application to understand the fundamentals of Node.js, file handling, JSON, and basic backend development.
